# BookBox

## Description
Онлайн-магазин книг с удобным каталогом, фильтрами по автору, жанру и издательству. Пользователи могут искать книги, читать отзывы, добавлять в избранное, оформлять заказы и отслеживать доставку. Для администраторов предусмотрено управление каталогом и обработка заказов. Приложение доступно в виде веб-сайта и мобильного приложения.
