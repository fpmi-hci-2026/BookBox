# Диаграмма компонентов

## Промпт для ИИ-агента

Работай как системный аналитик проекта BookBox. Входные материалы — отчёты ЛР1–ЛР3, модели заданий 2–3 и README трёх приложений. Сверяй термины с отчётами. Различай зафиксированные требования и проектные допущения.

Покажи BookBox-Web, BookBox-Mobile, BookBox-Server, серверные компоненты API, каталога, заказов и отчётности, БД и платёжный сервис. Обозначь направления зависимостей. Уточни, что внутренние компоненты представляют структуру проекта на этапе проектирования. Для диаграмм выдай редактируемый PlantUML и эквивалент на Mermaid.
