# Диаграммы объектов

## Промпт для ИИ-агента

Работай как системный аналитик проекта BookBox. Входные материалы — отчёты ЛР1–ЛР3, модели заданий 2–3 и README трёх приложений. Сверяй термины с отчётами. Различай зафиксированные требования и проектные допущения.

Создай две иллюстрации с вымышленными данными: заказ на одну книгу с отклонённой и успешной попытками оплаты и активный предзаказ с неизвестным сроком. Покажи экземпляры, значения ключевых атрибутов и связи. Сверь типы экземпляров с диаграммами классов. Для диаграмм выдай редактируемый PlantUML и эквивалент на Mermaid.
