# Пользовательские истории

## Промпт для ИИ-агента

Работай как системный аналитик проекта BookBox. Входные материалы — отчёты ЛР1–ЛР3, модели заданий 2–3 и README трёх приложений. Сверяй термины с отчётами. Различай зафиксированные требования и проектные допущения.

Уточни исходные пять историй Ани, Дмитрия, Ольги, Сергея и Ирины. Сохрани их цели и платформы. Добавь истории про повтор оплаты, изменение остатка, обработку заказа, уведомление о поступлении и CSV. Для каждой дай ID, роль, действие, ценность, 4–7 проверяемых критериев, приоритет с обоснованием и зависимость, если она есть. Покажи связь с ЛР2 §§7 и 9.
