# Диаграммы последовательности

## Промпт для ИИ-агента

Работай как системный аналитик проекта BookBox. Входные материалы — отчёты ЛР1–ЛР3, модели заданий 2–3 и README трёх приложений. Сверяй термины с отчётами. Различай зафиксированные требования и проектные допущения.

Для UC-01–UC-05 подготовь по одной диаграмме. Выдели участника, интерфейс, сервер, БД и платёжный сервис там, где они участвуют. Покажи запросы, ответы и альтернативные ветви из Use Case. Для UC-02 отдели повтор запроса той же попытки от новой попытки после отказа. Не придумывай реализацию HTTP-маршрутов. Для диаграмм выдай редактируемый PlantUML и эквивалент на Mermaid.
