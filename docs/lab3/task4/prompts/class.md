# Диаграммы классов

## Промпт для ИИ-агента

Работай как системный аналитик проекта BookBox. Входные материалы — отчёты ЛР1–ЛР3, модели заданий 2–3 и README трёх приложений. Сверяй термины с отчётами. Различай зафиксированные требования и проектные допущения.

Возьми модель заказа из задания 2 и дополни её двумя моделями: каталог и предзаказ. Используй атрибуты из ЛР1 §12 и ЛР2 §5, сохраняй русские подписи. Покажи атрибуты с типами, ассоциации, композиции и кратности. Сверь связующие сущности с ERD. Для диаграмм выдай редактируемый PlantUML и эквивалент на Mermaid.
