# Диаграмма и сценарии Use Case

## Промпт для ИИ-агента

Работай как системный аналитик проекта BookBox. Входные материалы — отчёты ЛР1–ЛР3, модели заданий 2–3 и README трёх приложений. Сверяй термины с отчётами. Различай зафиксированные требования и проектные допущения.

Выбери пять целей: найти учебник, оформить и оплатить заказ, оформить предзаказ, добавить книгу, посмотреть статистику. Построй одну диаграмму с границей системы и акторами. Для каждого варианта дай идентификатор, роль, триггер, предусловия, нумерованные шаги, альтернативы с номерами шагов и результат. Свяжи сценарии с историями US-01–US-10. Для диаграмм выдай редактируемый PlantUML и эквивалент на Mermaid.
