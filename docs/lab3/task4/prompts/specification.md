# Техническая спецификация

## Промпт для ИИ-агента

Работай как системный аналитик проекта BookBox. Входные материалы — отчёты ЛР1–ЛР3, модели заданий 2–3 и README трёх приложений. Сверяй термины с отчётами. Различай зафиксированные требования и проектные допущения.

На основе US-01–US-10 и UC-01–UC-05 собери спецификацию SRS. Включи цель и границы, роли, требования с идентификаторами и трассировкой, модель данных, интерфейсы, нефункциональные требования, условия приёмки и открытые вопросы. Не выдумывай стек и численные цели производительности.
