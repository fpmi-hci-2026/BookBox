# Диаграмма пакетов

## Промпт для ИИ-агента

Работай как системный аналитик проекта BookBox. Входные материалы — отчёты ЛР1–ЛР3, модели заданий 2–3 и README трёх приложений. Сверяй термины с отчётами. Различай зафиксированные требования и проектные допущения.

Предложи логические пакеты сервера для API, идентификации, каталога, заказов, аналитики, хранения и интеграций. Покажи направленные зависимости пакетов. Сверь названия с диаграммой компонентов и явно обозначь целевую структуру. Для диаграмм выдай редактируемый PlantUML и эквивалент на Mermaid.
