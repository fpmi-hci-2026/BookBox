# Логическая ERD

## Промпт для ИИ-агента

Работай как системный аналитик проекта BookBox. Входные материалы — отчёты ЛР1–ЛР3, модели заданий 2–3 и README трёх приложений. Сверяй термины с отчётами. Различай зафиксированные требования и проектные допущения.

Примени getanalyst-database-designer, включая релевантные правила из database-design-standards.md. Вход: ЛР1 §12, ЛР2 §5, модель заказа задания 2, UC-01–UC-05. Проверь M:N, обязательность связей и идентификаторы. Выдели позиции заказа, попытки оплаты, связи книг с авторами и жанрами. Сохрани цену и адрес заказа, учти привязку попыток к заказу и уникальность ссылки провайдера. Выдай логическую ERD и объясни, какие решения оставлены до выбора СУБД. Для диаграмм выдай редактируемый PlantUML и эквивалент на Mermaid.
