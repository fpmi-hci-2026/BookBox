# Диаграммы деятельности

## Промпт для ИИ-агента

Работай как системный аналитик проекта BookBox. Входные материалы — отчёты ЛР1–ЛР3, модели заданий 2–3 и README трёх приложений. Сверяй термины с отчётами. Различай зафиксированные требования и проектные допущения.

Используй UC-02 и UC-03. Для заказа перенеси ветвления из диаграммы задания 2. Для предзаказа покажи переход от карточки к подтверждению, повторную проверку доступности и два исхода. Разведи действия покупателя и системы. Покажи точки завершения и условия на каждой развилке. Для диаграмм выдай редактируемый PlantUML и эквивалент на Mermaid.
