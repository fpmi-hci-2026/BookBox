# Диаграмма развёртывания

## Промпт для ИИ-агента

Работай как системный аналитик проекта BookBox. Входные материалы — отчёты ЛР1–ЛР3, модели заданий 2–3 и README трёх приложений. Сверяй термины с отчётами. Различай зафиксированные требования и проектные допущения.

Расположи браузер и мобильное приложение на устройстве пользователя, веб-клиент, API и БД на соответствующих узлах, платежи у внешнего провайдера. Покажи HTTPS и закрытое соединение с БД. Отметь, что это целевая топология без привязки к конкретному облаку. Для диаграмм выдай редактируемый PlantUML и эквивалент на Mermaid.
