# Пользовательские истории BookBox после уточнения

US-01–US-05 развивают пять историй из [задания 1](../../lab3.md#13-пользовательские-истории-и-критерии-приёмки). US-06–US-10 добавляют требования, которые уже прослеживаются в раскадровках и проверочных сценариях [ЛР2](../../lab2.md#9-интерактивные-раскадровки-и-совокупная-диаграмма-взаимодействия).

## Уточнённые истории

### US-01. Поиск учебника по бюджету

Как покупатель, я хочу искать учебник и ограничивать цену в мобильном приложении, чтобы быстро найти подходящую книгу в пределах бюджета.

**Приоритет High.** Поиск ведёт к основной покупке. **Зависимость:** доступен каталог.

1. Поиск доступен с главного экрана и из каталога.
2. После ввода названия выдача показывает название, автора, цену и наличие.
3. При пределе 30 BYN книга за 30 BYN остаётся в выдаче, книга дороже отфильтровывается.
4. Если совпадений нет, приложение предлагает изменить запрос или сбросить ограничение цены.
5. Поле цены и результат поиска доступны без горизонтальной прокрутки экрана.

### US-02. Заказ книги в подарок

Как покупатель, я хочу указать получателя и добавить подарочную упаковку на веб-сайте, чтобы отправить книгу напрямую.

**Приоритет Medium.** Подарочное оформление расширяет базовый заказ. **Зависимость:** корзина и базовое оформление.

1. Из корзины можно перейти к оформлению выбранной книги.
2. В форме доступны имя и адрес получателя и переключатель упаковки.
3. При включении упаковки итог пересчитывается до подтверждения заказа.
4. После успешного оформления подтверждение показывает номер заказа и выбранный вариант доставки.
5. Поля имеют видимые подписи, управляются с клавиатуры и доступны при ширине окна 375–1440 px.

### US-03. Предзаказ редкого издания

Как покупатель, я хочу искать нужное издание по библиографическим данным и бронировать его, чтобы получить книгу после поступления.

**Приоритет Medium.** Предзаказ нужен при ограниченном ассортименте. **Зависимость:** каталог и учётная запись.

1. Поиск принимает автора, издательство и год и показывает записи, удовлетворяющие всем заданным условиям.
2. Действие «Предзаказ» доступно для временно отсутствующей книги, допущенной к предзаказу.
3. После подтверждения система показывает номер предзаказа и ожидаемый срок, если он известен.
4. Если право на предзаказ отозвано до подтверждения, запись не создаётся и показывается актуальное состояние.
5. Форма доступна с клавиатуры и сохраняет видимый фокус.

### US-04. Добавление книги

Как администратор, я хочу добавить книгу в каталог, чтобы покупатели смогли найти новое издание.

**Приоритет High.** Функция нужна для пополнения каталога. **Зависимость:** разграничение прав.

1. Форма добавления доступна администратору.
2. Название, автор, издательство и цена обязательны.
3. При некорректной цене запись не создаётся, сообщение связано с нужным полем.
4. При успешном сохранении карточка появляется в каталоге и находится по названию.
5. Заполнение и отправка формы доступны с клавиатуры.

### US-05. Статистика продаж

Как аналитик, я хочу выбрать период и увидеть продажи и популярные книги, чтобы принимать решения об ассортименте.

**Приоритет Medium.** Данные нужны после появления заказов. **Зависимость:** подтверждённые продажи.

1. Отчёт доступен пользователю с правом просмотра аналитики.
2. При начальной дате позднее конечной интерфейс показывает ошибку периода.
3. Для допустимого периода отчёт показывает сумму, число подтверждённых заказов и продажи по книгам.
4. При отсутствии подтверждённых заказов отображается поясняющее пустое состояние.
5. Клавиатурный фокус виден, таблица читаема при ширине окна от 768 px.

## Новые истории

### US-06. Повтор онлайн-оплаты

Как покупатель, я хочу повторить отклонённую оплату, чтобы завершить оформление без повторного ввода данных.

**Приоритет High.** Отказ платежа не должен срывать покупку. **Зависимость:** базовый заказ и платёжный сервис.

1. После отказа интерфейс показывает ошибку и действие «Повторить оплату».
2. Адрес, выбранная доставка и состав заказа сохраняются.
3. Осознанный повтор создаёт новую попытку для того же заказа.
4. При успехе показывается один номер заказа. Повтор запроса той же попытки не создаёт вторую оплату.

### US-07. Изменение наличия при оформлении

Как покупатель, я хочу узнать, какая позиция стала недоступной, чтобы исправить корзину до списания денег.

**Приоритет High.** Проверка предотвращает оплату недоступного товара. **Зависимость:** каталог и корзина.

1. При оформлении система сверяет количество в корзине с доступным остатком.
2. При нехватке выводится название недоступной позиции.
3. Пока есть недоступная позиция, запрос оплаты не отправляется.
4. Можно вернуться в корзину, исправить количество и снова перейти к оформлению.

### US-08. Обработка оплаченного заказа

Как администратор, я хочу передать подтверждённый заказ в доставку, чтобы покупатель мог отслеживать его выполнение.

**Приоритет High.** Без передачи заказ не сможет перейти к доставке. **Зависимость:** подтверждённый заказ.

1. Администратор видит подтверждённый заказ и его позиции.
2. Действие передачи доступно для заказа, готового к доставке.
3. После передачи статус обновляется и отображается покупателю в деталях заказа.
4. Повторное нажатие не создаёт ещё одну передачу для того же заказа.

### US-09. Уведомление о поступлении предзаказа

Как покупатель, я хочу получить уведомление о поступлении книги, чтобы вовремя завершить покупку.

**Приоритет Medium.** Уведомление связывает заявку с поступлением товара. **Зависимость:** US-03 и актуальный остаток.

1. Уведомление относится к активному предзаказу и содержит название книги.
2. Оно создаётся при переходе предзаказа в состояние «Доступен к покупке».
3. Переход из уведомления открывает детали соответствующего предзаказа.
4. Повторная обработка того же перехода не создаёт дублирующее уведомление.

### US-10. Экспорт статистики

Как аналитик, я хочу выгрузить статистику за выбранный период в CSV, чтобы продолжить анализ во внешнем инструменте.

**Приоритет Low.** Для первого просмотра достаточно отчёта в интерфейсе. **Зависимость:** US-05.

1. Экспорт доступен пользователю, который может просматривать отчёт.
2. В CSV попадают данные выбранного периода.
3. В файле есть заголовки столбцов и строки продаж по книгам.
4. При ошибке подготовки файла показывается сообщение, позволяющее повторить экспорт.
