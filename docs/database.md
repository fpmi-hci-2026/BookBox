## Концептуальные сущности

В ЛР1 определена базовая объектная модель BookBox. Основные сущности: книга, пользователь, заказ, администратор, отзыв, корзина, издательство и жанр.

| Сущность | Основные атрибуты |
|---|---|
| Книга | ID, название, автор, издательство, год, жанр, ISBN, цена, описание, обложка, рейтинг, наличие |
| Пользователь | ID, имя, email, телефон, пароль, адрес доставки, история заказов, избранное |
| Заказ | ID, пользователь, состав, дата, статус, сумма, адрес доставки, способ оплаты |
| Отзыв | ID, пользователь, книга, текст, оценка, дата |
| Корзина | ID, пользователь, позиции, количество, сумма |
| Издательство | ID, название, страна, сайт |
| Жанр | ID, название, описание |

## Основные связи

- Пользователь размещает много заказов (1:N).
- Заказ содержит позиции с книгами; связь заказа и книг — многие-ко-многим через позиции заказа.
- Книга может иметь много отзывов (1:N).
- Книга может относиться к нескольким жанрам, жанр включает много книг (M:N).
- Каждая книга связана с издательством (N:1).
- Пользователь имеет корзину и избранное; их состав связан с книгами.

В ЛР2 модель дополнена позициями заказа, платежами, адресами доставки, уведомлениями, подборками и промокодами.
