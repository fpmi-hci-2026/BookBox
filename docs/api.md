# API проекта

## Назначение

BookBox состоит из веб-клиента, мобильного клиента и серверного приложения. Клиенты обращаются к серверу за каталогом, поиском, данными аккаунта, корзиной, заказами и отзывами; административные операции выполняются через защищённые функции управления.

## Основные группы операций

| Область | Примеры операций |
|---|---|
| Каталог | Получить список книг, открыть карточку книги, получить жанры и издательства |
| Поиск | Выполнить поиск по запросу, применить фильтры и сортировку |
| Аккаунт | Зарегистрироваться, войти, прочитать и обновить профиль |
| Избранное и корзина | Добавить/удалить книгу, изменить количество, получить текущий состав |
| Заказы | Создать заказ, прочитать историю и статус, повторить оплату при ошибке |
| Отзывы | Получить отзывы и оценки, отправить отзыв; модерировать его администратору |
| Администрирование | Создать или изменить книгу, обработать заказ, управлять справочниками |
| Аналитика | Получить агрегаты продаж за период и экспортировать отчёт |
