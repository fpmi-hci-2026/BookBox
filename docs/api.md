## Контракт API BookBox

API спроектирован в OpenAPI 3.0.3 и проверен на Mock-сервере в рамках ЛР4.

- [Маршруты, методы и коды ответов](lab4/routes.md)

- [Интерактивная документация Swagger UI](lab4/api.html)

Базовый URL проекта: `https://api.bookbox.example/v1`. Формат данных — JSON, ошибки — `application/problem+json` (RFC 7807), аутентификация — Bearer JWT. Для локальной проверки Mock-сервер запускается командами:

```bash
npm install
npm run mock:api
npm run test:api
```

## Назначение

BookBox состоит из веб-клиента, мобильного клиента и серверного приложения. Клиенты обращаются к серверу за каталогом, поиском, данными аккаунта, корзиной, заказами и отзывами; административные операции выполняются через защищённые функции управления.

## Основные группы операций

| Область | Маршруты | Примеры операций |
|---|---|---|
| Каталог | `/books`, `/genres`, `/publishers` | Получить список книг, открыть карточку, получить справочники |
| Поиск | `/books` | Поиск по `q`, фильтры по жанру, издательству, цене и наличию |
| Аккаунт | `/auth/register`, `/auth/login`, `/me` | Зарегистрироваться, войти, прочитать и обновить профиль |
| Корзина и избранное | `/me/cart`, `/me/favorites` | Добавить или удалить книгу, изменить количество |
| Заказы | `/me/orders`, `/me/orders/{orderId}/payment-attempts` | Создать заказ, прочитать историю, оплатить и повторить оплату |
| Предзаказы | `/me/preorders` | Оформить и отменить предзаказ |
| Уведомления | `/me/notifications` | Получить уведомления и отметить прочитанным |
| Отзывы | `/books/{bookId}/reviews`, `/admin/reviews` | Прочитать, отправить и модерировать отзыв |
| Администрирование | `/admin/books`, `/admin/orders/{orderId}/ship` | Создать или изменить книгу, передать заказ в доставку |
| Аналитика | `/analytics/sales`, `/analytics/sales/export` | Получить агрегаты продаж и CSV-выгрузку |
