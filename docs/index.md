# BookBox — Онлайн-магазин книг

## О проекте

BookBox — это онлайн-магазин книг, предоставляющий пользователям удобный каталог с фильтрами по автору, жанру, издательству и цене. Покупатели могут искать книги, читать отзывы, добавлять товары в избранное, оформлять заказы и отслеживать их доставку. Для администраторов предусмотрена панель управления каталогом и обработка заказов. Проект реализуется в виде веб-сайта и мобильного приложения для Android/iOS.
