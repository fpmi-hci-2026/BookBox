```bash
npm install

```

Проверка контракта:

```bash
npm run test:api
```

## Зависимости и допущения

- Задания 3–4 построены на требованиях и моделях из заданий 1–2.
- Для физической схемы выбрана PostgreSQL как проектное допущение; репозиторий BookBox-Server пока не содержит реализации, поэтому перед подключением схемы выбор нужно подтвердить.
- Схема описывает MVP API и включает каталог, аккаунты и роли, корзину, избранное, заказы, платежи, предзаказы, отзывы, уведомления и данные для аналитики.
- Mock-сервер проверяет контракт, но не реализует бизнес-логику: остатки, роли, владение заказом и идемпотентность должны проверяться сервером.
- Публикация Swagger UI на GitHub Pages произойдёт после слияния ветки `lab4` в `main`; относительная страница [api.html](api.html) работает и локально.
