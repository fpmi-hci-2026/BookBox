# Диаграмма файлов приложения

## Структура проекта

BookBox разделён на основной репозиторий документации и три самостоятельных репозитория приложений, подключённых в основном проекте как Git-сабмодули.

| Репозиторий/каталог | Назначение |
|---|---|
| `BookBox/` | Документация, требования, API и проектные материалы |
| `BookBox-Web/` | Веб-приложение |
| `BookBox-Server/` | Серверное приложение |
| `BookBox-Mobile/` | Мобильное приложение |
| `docs/` | Отчёты лабораторных работ, проектная документация и GitHub Pages |
| `docs/images/` | Иллюстрации, схемы и макеты для отчётов |
| `scripts/diagrams/spec/` | JSON-спецификации генерируемых диаграмм ЛР2 |
| `mockups/` | HTML/CSS-исходники эскизов, wireframes и дизайн-макетов |
| `maps/` | Исходные данные и генераторы Impact Map и CJM |
| `storyboards/` | Исходники интерактивных раскадровок |
